游戏内语音

装上语音 mod 就能在游戏里直接开口说话：站得近的人能听见你，小队里隔多远都能聊。语音完全可选，不装也能正常进服玩

这是什么？

装上语音 mod 后，你可以在游戏里直接开口说话：

  • 附近语音：站得近的人能听见你，越远声音越小，48 格外就听不到了。声音有方向，左边的人说话从左耳出来。
  • 小队频道：和朋友建个小队，不管隔多远都能听到彼此，适合一起下星渊、一起逛街。

语音完全是可选的

不装 mod 一样能正常进服、正常玩，只是听不到也说不了。别人说话不会打扰你，你也不会因为没装被踢。

要装什么？

只要装一个客户端 mod：Simple Voice Chat（简单的语音聊天）。

你用的加载器下载哪个
Fabricvoicechat-fabric-…+26.3
NeoForgevoicechat-neoforge-…+26.3
  • 游戏版本一定要选 26.3（和服务器一致），mod 文件名末尾也必须是 +26.3。
  • 版本号前半段（如 2.6.27）不用和服务器完全一样，选最新的就行。
  • 官方下载页：Modrinth 搜「Simple Voice Chat」（https://modrinth.com/plugin/simple-voice-chat ），或 CurseForge 同名项目。别从来路不明的网盘下。
  • 从没装过 mod？选 Fabric 最省事。

用启动器安装（PCL2 / HMCL）

PCL2

  1. 打开 PCL2 →「下载」→「Minecraft」→ 选 26.3。
  2. 在安装页勾上 Fabric（会自动带上 Fabric API，保留即可）→ 开始安装。
  3. 装好后在左侧选中这个版本 →「版本设置」→「Mod 管理」（或顶部「下载」→「Mod」）。
  4. 搜「Simple Voice Chat」或「简单的语音聊天」→ 选 26.3 / Fabric 的版本 → 下载到这个版本。
  5. 启动游戏，主菜单右下角 Mod 数变多、进服后按 V 能打开语音界面，就装好了。

HMCL

  1. 打开 HMCL →「下载」→「游戏」→ 选 26.3。
  2. 勾选 Fabric（Fabric API 一起勾上）→ 安装。
  3. 回到主页选中这个版本 →「版本设置」→「模组管理」→「下载」。
  4. 搜「Simple Voice Chat」→ 选适配 26.3 / Fabric 的文件 → 安装。
  5. 启动游戏，进服按 V 能打开语音界面即成功。

想用 NeoForge 的同学，把上面的 Fabric 换成 NeoForge，下载 mod 时选 NeoForge 版即可。已经有自己的整合包？把 voicechat-fabric-…+26.3.jar（或 neoforge 版）丢进对应版本的 mods 文件夹就行。

第一次打开时：电脑可能会弹「是否允许 Java 使用麦克风」——点允许。Mac 用户如果没弹，去「系统设置 → 隐私与安全性 → 麦克风」给启动器 / Java 打勾。

常用按键

按键作用
V打开语音主界面（设置、调音量、进小队都从这里进）
G直接打开小队界面
Caps Lock（大写锁定）按住说话（默认模式下）
M一键静音 / 取消静音自己的麦克风
N一键关掉整个语音（自己不说也不听）

按键都可以在「选项 → 控制 → 按键绑定」里找到「Voice Chat」一栏改成你习惯的键。

怎么说话

按 V → 点右上角的「设置」（齿轮）：

  1. 选麦克风：在「麦克风」里选你在用的那个（耳机麦 / 外接麦）。
  2. 选说话方式：
    • 按住说话（PTT）：默认模式。按住 Caps Lock 才会发声，松开就闭麦。推荐新手用，不会把敲键盘、家里电视的声音传出去。
    • 自由麦（语音激活）：不用按键，一说话就自动开麦。用这个模式时把「激活阈值」滑条往右拖一点，直到不说话时那根绿色音量条不亮为止，避免环境噪音一直被传出去。
  3. 测试：设置里有「测试麦克风」，能听到自己的回声就说明麦克风通了。

说话时屏幕左下会出现一个小麦克风图标；别人说话时他头顶会出现小喇叭。

小队频道与静音别人

建小队 / 加入小队

  1. 按 G（或 V → 小队按钮）。
  2. 建小队：输入一个名字，想只让朋友进可以设个密码 → 创建。
  3. 加入小队：在同一个界面的列表里点别人的小队 → 有密码就输入密码。
  4. 进了小队后，队友之间隔多远都能听到。小队类型一般选默认（普通）就好。
  5. 离开：再按 G，点「离开小队」。

静音 / 调小某个人

  • 按 V → 点「音量调节」（喇叭图标）→ 列表里找到那个人 → 把他的音量滑条拖到 0，或点他名字旁的静音按钮。
  • 只对你自己生效，对方不会知道。
  • 觉得所有人都太吵：V → 设置里把「语音音量」整体调小；或者直接按 N 关掉语音。
