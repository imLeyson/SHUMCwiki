领地帮工

雇帮工照看田地、茶园、动物和水塘：四种工作、契约与日薪、熟练度、心情、平衡规则与收益估算

一句话

花茶屋币雇一位帮工姑娘住进你的领地，帮你照看田、茶、动物和水塘，收成放进你指定的箱子。她干得比你亲手干少、品质低，而且你得在线、不能挂机太久她才全速干活——亲手玩依然最划算、最特别，她是帮你省力的。

怎么雇：一步一步

  1. 买契约：主菜单 🛒 商业街（/npcshop）第 2 行的 🏢 茶屋职介所（或 /bangong agency），选一种工作买 📜 帮工契约。
  2. 放下她：拿着契约右键自己领地里的地面，她就出现在那一格上（要一格实心地面、上面空两格）。这一格就是她的「岗位」。
  3. 绑箱子：右键她打开工作页 → 📦 绑定箱子，30 秒内右键一个箱子 / 陷阱箱 / 木桶（离岗位 16 格以内、同一块地里）。也可以先拿着契约 Shift+右键箱子预绑，放下她时自动绑好。
  4. 开工：农夫 / 茶娘 / 养殖员按正常人的手速一件接一件干，大约 0.5 秒一格，这一片干完马上找下一片，范围里没活了才走回岗位（之后每 10 秒再看一眼）。渔夫一竿一竿地钓。收成放进箱子。
  5. 想看所有帮工：/bangong（别名 /helper、/bg、/帮工）打开 👩‍🌾 帮工名单，或 /lingdi 领地管理第 2 行的 👩‍🌾 帮工。名单里左键打开她的工作页，右键让她发光 5 秒好找。

能放在哪、能放几个

  • 你自己是主人的领地（在子领地里按整块领地算）。别人的领地、野外、不是自己的地都不行，会告诉你原因。
  • 小镇里：镇长 / 助理可以在镇上任何地方雇「小镇公共帮工」（公共农田）；居民只能雇在自己的子领地里。
  • 每人最多 3 个（所有领地加起来）。镇长 / 助理雇的小镇公共帮工不占名额，只受小镇名额限制。
  • 每块地最多几个：普通领地 / 子领地按面积，≤ 1000 格 1 个、≤ 4000 格 2 个、更大 3 个；小镇公共地按繁荣度 Lv1–5：2 / 2 / 3 / 3 / 4 个。两个帮工的岗位不能紧挨着。
  • 作业范围：以岗位为中心的方块，默认 5×5，熟练度越高能开越大（见下）。范围永远夹在这块地里，岗位贴边时会自动变窄。工作页 🧭 范围：左键扩大、右键缩小。

工资、心情与辞退

日薪

  • 契约是一次性的；日薪只在她真的干了活的日子扣：当天第一次真要干活时，按她那一刻的工作和等级从你的钱包扣，动作栏会显示「今天开工，日薪 −190 币（农夫 Lv.2，钱包）」。田里没熟、没鱼、没动物可照顾 = 那天不扣。
  • 当天中途升级不补扣，第二天按新等级算。
  • 欠薪：钱包扣不到，她就停工、摇头，头顶「💢 欠薪中…」，聊天提醒你（带打开名单的按钮）。到工作页 💰 补发当天那份（谁点谁出钱，搭子也能替你付），补完马上开工。

辞退与换工作

  • 🗑 辞退：退当初签的契约价的 70%（农夫 2,000 → 1,400、茶娘 / 养殖员 1,500 → 1,050、渔夫 1,200 → 840），欠的薪水从退款里扣。要先过确认页。
  • 🔁 换工作：工作页 🔁，手续费 300 币，熟练度保留 50%，外观跟着换，今天的计数清零；档案里旧工作的成绩保留。第二天起按新工作、新等级算日薪；以后辞退仍按当初签的契约价退。
  • 📍 挪岗位：工作页 📍（右键可以描一遍作业范围看看）。
  • ✏ 改名：工作页 ✏，或 /bangong rename 名字（给最近打开工作页的那位改名，1–6 个字）。

平衡：为什么亲手干还是更好

  • 品质封顶 ★★ 银星：金星、珍品、鱼王、大师品质只有亲手做才有。茶娘冲的茶 70% ★ 凡品、30% ★★。
  • 不暴击：不触发 🌾 黄金大丰收。
  • 不吃加成：专精、天赋、专精锄头、丰收之神、巨型作物、香料、搭子、许愿池、鱼饵 / 拟饵 / 鱼竿 / 连击 / 节日 / 运势一律不算。肥料照常生效并消耗一茬（她用的是你的地）。
  • 不记收集：不记农耕图鉴 / 里程碑、钓鱼图鉴 / 个人最佳 / 全服纪录 / 钓鱼大赛，不给你专精经验，也不给公会经验。
  • 渔夫不出稀有鱼：传说 / 稀有鱼（黄金锦鲤王、远古活化石鱼等）和宝物都钓不到，也没有宝箱。
  • 每天有上限，满了头顶「😴 今天收工啦」。
  • 不离线挂机：你在线、她那块区块加载着才干活。
  • 💤 老板挂机她也偷懒：你 10 分钟没走动、没转视角、没聊天、没交互，你的所有帮工干活慢一半（干一批歇一批，歇的时间和上一批干的一样长），头顶「💤 老板不在，偷个懒」。你一动，她最多 2 秒内恢复，还会说「老板回来啦，开工开工！」。被水流冲着走、坐在载具里漂不算动静。小镇公共帮工跟着雇她的那位镇长 / 助理算。
  • 她的收成拿去 /sell 照常算进每日出货额度。

好玩的小细节

  • 会动：干活时一格一格走过去，面朝目标、脚下扬起小尘土；闲着时会转头看附近的玩家。附近 24 格内有玩家时还有小动画：🌾 农夫拿着锄头低头收割，碎屑飞溅，收成画一道弧飞进箱子；🐔 养殖员剪毛拿剪刀、挤奶时空桶变牛奶桶、喂食拿着饲料；🎣 渔夫拿钓竿甩出红色浮漂，浮漂在水上一沉一浮，咬钩时一沉、溅起水花，鱼飞进箱子。（工具只是样子，不会掉。）
  • 头顶小气泡：📦 箱子满了 / 📦 还没绑箱子 / 💢 欠薪中 / 😴 今天收工啦 / 🏚 领地不在了，偶尔冒一句可爱台词。
  • 天气和季节：下雨且岗位露天时头顶一圈水花，「☂ 雨天也要加油！」；冬天露天手变慢（渔夫上钩率 −10%），岗位头顶有玻璃（温室）或在室内就不受影响。
  • 小惊喜（每个帮工每天最多一次）：捡到茶屋币袋（5–20 币给你），或农夫 / 茶娘在田埂里捡到一包当季种子 / 抹茶种子。
  • 打招呼：你上线 3 秒后，帮工在聊天里报「老板回来啦！昨天收了 X 格，今天收了 Y 格」。
  • 📜 帮工档案：工作页 📜，看她的名片（工作、熟练度、心情、上工日期）、一辈子的成绩、收到的茶、小惊喜、今天 / 昨天的成绩。

和小镇、公会联动

  • 小镇：镇长 / 助理能雇小镇公共帮工；镇上（含子领地）每个帮工给繁荣度 +20（最多算 4 个）。
  • 公会：你在 🛡 公会里时，工作页多两个按钮——
    • 🛡 工资从公会银行付：你的职位要有「💰 取用银行」，占你当天的取钱额度，银行流水会记一条；银行或额度不够时退回扣你的钱包，都不够才欠薪。
    • 🛡 交货到公会仓库：收成直接放进公会仓库（满了她就停，头顶「公会仓库满啦」）；茶娘 / 养殖员的原料仍从你的箱子拿。

她不会被欺负

帮工无敌、不能交易（右键永远是工作页）、不繁殖、不能拴、不坐船 / 矿车、不进传送门、不会被雷劈变身或被僵尸感染，怪物不会盯上她，也不会招铁傀儡。推不动，被水冲走或挪开 1 格以上下一秒就回岗位。领地被放弃 / 转手 / 缩小到不含岗位时她会停工，头顶「🏚 领地不在了」，你可以辞退拿退款。

常见问题

我下线了她还干活吗？

不干。你在线、她那块区块加载着才干活。你挂机 10 分钟以上她也只干一半。

她为什么不动了？

看她头顶的气泡：箱子满了、没绑箱子、欠薪、今天收工了（到上限）、领地不在了。田里没有成熟作物时她也会闲着。

她会帮我种新地吗？

农夫只收成熟的作物并原地补种，不会开新田；先把田种好。

她能钓到传说鱼吗？

不能，渔夫只钓普通鱼，品质最高 ★★。

雇几个最划算？

每人最多 3 个。一般建议：特色作物田一个农夫 + 抹茶田一个茶娘；养殖员按需要原料再雇。
